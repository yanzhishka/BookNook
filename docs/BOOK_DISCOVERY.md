# Поиск и загрузка книг

Поиск доступен вошедшему пользователю в окне «Добавить книгу». По умолчанию показаны произведения с открытым источником текста, затем можно искать по названию или автору и выбирать язык. Пустой запрос открывает начальную подборку для выбранного языка.

Поддерживаются русский, английский, французский, немецкий, испанский, итальянский, португальский, украинский и польский. Язык относится к тексту издания, а не к языку интерфейса. Переводы автоматически не создаются.

## Источники

- Викитека/Wikisource: поиск по названиям и разделам произведений на страницах авторов. Поиск по названию и библиография автора запрашиваются параллельно: множество совпадений фамилии в названиях не скрывает произведения автора. Совпадение слов внутри постороннего текста не используется. Если у книги несколько изданий, пользователь выбирает конкретное. Главы загружаются в порядке оглавления.
- Open Library: дополнительный каталог при отключённом фильтре «Только с текстом». Наличие карточки, скана или обложки не считается доступностью текста. Карточку можно сохранить в планы и прикрепить свой файл.
- EPUB, PDF и TXT можно загрузить вручную. Описание произведения никогда не записывается вместо его текста.

Доступность зависит от содержания выбранного источника. Если глава отсутствует или загрузка прервалась, частичная книга не сохраняется: интерфейс предлагает повторить загрузку, выбрать другое издание или загрузить файл. Карточка без текста не открывает пустую читалку — на полке предлагается прикрепить EPUB.

## Устройство

`shared/bookCatalog.ts` задаёт контракт, языки и стартовые подборки. `book-proxy` обрабатывает `catalog_search` и `catalog_text`, требует авторизацию и обращается только к фиксированным доменам источников. Старые действия `search`/`text` сохранены для совместимости опубликованного клиента.

На стороне сервера HTML Викитеки разбирает LinkeDOM. Ссылки на главы извлекаются до удаления служебного оглавления, включая оглавления с пометкой `noprint`. Двоеточие разрешено в названии книги и главы; для таких названий пространство имён проверяется через MediaWiki (`ns = 0`), поэтому страницы авторов и служебные разделы не импортируются. Ограничения загрузки: 4 запроса одновременно, 120 страниц, 4 уровня оглавления, 8 MiB HTML. Таймаут запроса источника — 12 секунд; новые главы перестают запрашиваться после 40 секунд. Серверный кеш ограничен 100 записями/24 MiB и живёт 5 минут. Это не постоянное хранилище книги.

Клиент собирает главы в промежуточный EPUB и использует существующий безопасный импортёр: стихи, оглавление, внутренние ссылки и сноски превращаются в структурированный документ. HTML источника не вставляется в DOM приложения. Внешние иллюстрации не скачиваются; ссылка на источник и предупреждение сохраняются в документе. Поиск, смена языка и закрытие окна отменяют устаревшие ответы.

## Проверка

```sh
npm test
npm run build
npx deno check supabase/functions/book-proxy/index.ts
```

Тесты покрывают выбор языка, редиректы, поиск автора без подмены авторства биографиям, отдельный выбор издания, порядок глав, отсутствующие главы, частичный отказ провайдера, карточки без текста, безопасный импорт и внутренние ссылки/сноски. Внешние запросы в тестах замещены предсказуемыми ответами; доступность живых источников проверяется отдельно через интерфейс.

Документация провайдеров: [MediaWiki Search API](https://www.mediawiki.org/wiki/API:Search), [Parsing wikitext](https://www.mediawiki.org/wiki/API:Parsing_wikitext), [Open Library Search API](https://openlibrary.org/dev/docs/api/search).
