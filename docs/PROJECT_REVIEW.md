# Ревизия BookNook — 2 ноября 2026

## Оценка проекта

Сильная сторона BookNook — связка «найти книгу → читать → сохранить мысль → обсудить». Для неё уже есть самостоятельная читалка с обработкой стихов, глав и сносок, приватная библиотека и единое сообщество The Grid. Следующий этап — сделать этот путь устойчивым на больших библиотеках и разных изданиях.

Основной долг сейчас в обработке состояния и отказов: импорт, загрузка данных, вложенные диалоги и сохранение профиля могли давать неверный результат даже при нормальной вёрстке. В этой ревизии исправлены конкретные такие сценарии. Принятый внешний вид и прежние доработки сохранены.

## Что исправлено

| Область | Проблема и результат |
| --- | --- |
| Поиск автора | Большое число совпадений фамилии в названиях отключало библиографию. Теперь обе ветки поиска работают параллельно. Учитываются страницы с отдельными жанровыми разделами без общего заголовка «Произведения». Известные книги из существующей стартовой подборки показаны раньше; пагинация не теряет результаты. Живой запрос «Пушкин» возвращает первыми «Евгений Онегин» и «Капитанская дочка» с именем автора. |
| Загрузка книги | Ссылки на главы собираются до удаления служебного оглавления, включая `noprint`. Порядок глав берётся из оглавления. Отсутствующие главы прерывают импорт вместо сохранения частичной книги. Двоеточие в настоящем названии разрешено; служебные пространства имён проверяются через MediaWiki. |
| EPUB | Текст блока совпадает с текстом его вложенной разметки, включая пробелы стихов и `pre`. Это устраняет расхождение координат выделений и чтения в новых импортах. Вложенные якоря `id`/`name` регистрируются отдельно: несколько разделов внутри одного XHTML больше не получают один переход. |
| Диалоги | Окно входа видно поверх темы. Только верхний диалог обрабатывает Tab и Escape; закрытие возвращает фокус, блокировка прокрутки сохраняется до закрытия последнего окна. Добавлены имена и описания диалогов. |
| Запись данных | Повторные нажатия не дублируют запросы входа и модерации. Во время входа нельзя переключиться на гостя или регистрацию. Успешное сохранение профиля не превращается в ошибку из-за последующего сбоя чтения; настоящая ошибка сохраняет черновик. Переход к своему профилю сбрасывает просмотр чужого. |
| Восстановление | Ошибка рендера или загрузки модуля показывает экран восстановления. Ошибка отдельного раздела оставляет основную навигацию доступной. Добавлена отдельная защита при запуске приложения. |
| Доступность и нагрузка | Обложка книги в режиме списка открывается Enter/Space. Курсор прекращает запросы кадров, когда перестаёт двигаться; при уменьшении движения используется обычный курсор. CSS также учитывает системную настройку уменьшения движения. |
| База данных | Удаление личной книги сохраняет её публичную подпись в ранее опубликованной цитате. Снимок книги при публикации по-прежнему строится сервером только из книги владельца. Клиент не может задавать статус модерации, ID или дату жалобы. Версии двух последних локальных миграций приведены к фактически применённым версиям. |
| Зависимости | Обновлены совместимые исправляющие версии Capacitor, Vite, PostCSS, LinkeDOM и транзитивных пакетов. `npm audit`: 15 → 4 находки, high/critical: 8 → 0. Оставшиеся четыре moderate относятся к цепочке Capacitor CLI / rimraf / glob / minimatch. Предлагаемый npm откат CLI до 4.x не применён. |

Патчи безопасности: [Capacitor 8.4.3](https://github.com/ionic-team/capacitor/security/advisories/GHSA-rvm3-566m-v7fv), [Vite 8.1.6](https://github.com/vitejs/vite/security/advisories/GHSA-rq7h-c2jc-7f22).

## Проверка и доставка

- `npm test`: **59/59**, до ревизии было 39 тестов. Новые проверки покрывают сбои и восстановление экранов, диалоги, повторные отправки, профиль, EPUB, поиск и главы.
- `npm run build`, проверка Deno для `book-proxy`, `git diff --check` проходят.
- Миграция `20261102134713_preserve_activity_snapshots_and_report_defaults.sql` применена в Supabase. SQL-регрессия от имени `authenticated` проверила сохранение подписи, серверные значения жалоб и запрет их подмены. Транзакция с тестовыми данными отменена.
- `book-proxy` развёрнут, версия **10**, проверка JWT включена. Через действующий endpoint проверены русский поиск автора и загрузка английского произведения с двоеточием в названии. Книги и публикации для этой проверки не сохранялись.
- В браузере при 1280×720 проверены запуск без ошибок консоли, открытие книги с клавиатуры, границы читалки, поиск, вложенное окно входа и возврат фокуса. Отдельный локальный стенд подтвердил восстановление после ошибки экрана без публикаций в сообществе.
- Клиентские изменения доступны локально на `http://127.0.0.1:5173/`. Новый веб-релиз на Vercel и сборка Android в эту ревизию не входят.

Логи, исходный снимок перед правками и снимки экрана находятся в исключённом из Git каталоге `work/`.

## План после ревизии и его статус

1. **Выполнено: загружать содержимое книги при открытии.** При входе приходят карточки полки и количество заметок. Документ и сами заметки выбранной книги загружаются отдельно. Добавлен ограниченный кеш документов в памяти текущей сессии с очисткой при выходе, смене владельца и замене книги.
2. **Выполнено: разделить управление состоянием читалки и The Grid.** Сохранение позиции, навигация, заметки, список тем, загрузка обсуждения и отправка ответов/тем вынесены в отдельные модули. Проверены ошибки, повторные действия и ответы сервера, пришедшие после смены книги или темы.
3. **Отложено по просьбе пользователя: работа без сети и выпуск.** Постоянный офлайн-кеш, синхронизация после перезапуска, публикация веб-версии и проверка установленного Android-клиента в это продолжение не входят.

Пункты 1 и 2 выполнены в указанном порядке. Архитектура, измерения и результаты проверки описаны в [LOADING_AND_STATE.md](LOADING_AND_STATE.md).

Исправление текстовых смещений относится к новым импортам. Уже сохранённые EPUB со старым расхождением пробелов автоматически не переписывались: для них нужно действие «Заменить EPUB». Ограничения сложных издательских стилей, DRM и фиксированной вёрстки описаны в [EPUB_READER.md](EPUB_READER.md). Живые проверки нескольких книг не доказывают полноту всех изданий во внешних каталогах.

Supabase Advisors после миграции не показывает проблем RLS или функций; остаётся предупреждение об отключённой [проверке скомпрометированных паролей](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection) и четыре информационных сообщения о пока неиспользованных индексах. Настройки тестового входа в этой ревизии не менялись.
