# B.Nook / W.Nook

B.Nook — пространство для чтения, личной библиотеки и общения о книгах. Сайт объединяет книжную полку, встроенную читалку, заметки, сообщество The Grid в одном спокойном интерфейсе.

Нажатие на логотип открывает выбор проекта: B.Nook для книг и W.Nook для совместного просмотра видео. У проектов общие аккаунт, профиль и тема оформления.

**Сайт:** [milliardarmedia.ru](https://milliardarmedia.ru)

W.Nook: [совместный просмотр](https://milliardarmedia.ru/?app=watch). Адрес с `www` перенаправляется на основной домен.

## Совместный просмотр

W.Nook создаёт комнаты по ссылке на YouTube либо доступный по HTTPS файл MP4 / WebM. Приглашённые участники после входа управляют общей паузой и перемоткой; громкость остаётся личной. Создатель выбирает видео и завершает просмотр. Есть список своих комнат, полноэкранный плеер и мобильная раскладка.

В плеере доступны общая скорость 0,25–2×, очередь с автопереходом, субтитры YouTube и личные SRT / VTT со сдвигом, отдельное окно и мини-плеер. Дополнительные настройки открываются иконками.

Для приглашений с других устройств используйте опубликованный сайт. Ссылка с `127.0.0.1` работает только на текущем компьютере. Подробнее: [устройство и проверка W.Nook](docs/WATCH_TOGETHER.md).

## Личная библиотека

В библиотеке можно находить и добавлять книги, распределять их по статусам, отслеживать прогресс и возвращаться к чтению с того места, на котором остановился. Поиск по названию и автору поддерживает девять языков. Открытые тексты загружаются из Викитеки с выбором издания и сохранением глав и сносок. Дополнительные карточки из Open Library помечены отдельно: к ним можно прикрепить свой файл. Подробнее: [поиск и загрузка книг](docs/BOOK_DISCOVERY.md).

## Читалка

Встроенная читалка сосредоточена на тексте и не перегружает экран лишними элементами. Доступны:

- светлая и тёмная темы;
- настройка шрифта, размера текста и межстрочного интервала;
- чтение на весь экран;
- сохранение выделенных фрагментов в заметки;
- запоминание текущего прогресса.

## Сообщество

The Grid объединяет обсуждения, цитаты и отзывы. Здесь можно найти тему по книге, автору или тексту, выбрать тип публикации, посмотреть свои темы или вопросы без ответов. Есть реакции, ответы и изображения; цитатой из читалки можно поделиться прямо здесь. Отдельная лента больше не нужна. Подробнее: [устройство сообщества](docs/COMMUNITY.md).

## Профиль и прогресс

Профиль показывает книги, прогресс, сохранённые заметки и достижения. Публичный профиль содержит общую информацию о читателе; личная библиотека и заметки доступны владельцу. За действия внутри сайта начисляется опыт, который формирует уровень пользователя.

## Гостевой режим

Сайт можно открыть без регистрации и познакомиться с публичным The Grid. Личная библиотека, публикации и профиль становятся доступны после входа.

## Интерфейс

B.Nook адаптирован для компьютеров и мобильных устройств, поддерживает светлое и тёмное оформление и может использоваться как веб-приложение или Android-приложение.

## Основа проекта

Интерфейс построен на React и TypeScript. Данные, профили и авторизация работают через Supabase, а веб-версия размещена на Cloudflare Pages. Доступ к личным данным и книгам ограничен на уровне базы данных.

Публикация из `main`, GitHub-релизы и откат: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).


## Локальная разработка

Требуется Node.js 22.18 или новее.

```sh
npm ci
cp .env.example .env.local
# Заполните VITE_SUPABASE_URL и VITE_SUPABASE_PUBLISHABLE_KEY в .env.local.
npm run dev
```

В клиентские `VITE_*` переменные добавляйте только публичный ключ Supabase. Серверные ключи туда не подходят. `.env.local` исключён из Git. Для отдельной среды разработки используйте URL и публичный ключ её проекта.

```sh
npm test
npm run build
```

Проверка записи и прав доступа в выбранном Supabase-проекте требует явного включения. Скрипт создаёт два временных аккаунта, проверяет книги, заметки и изоляцию пользователей, затем удаляет созданные аккаунты. Используйте тестовый проект, где не требуется подтверждать email (`mailer_autoconfirm=true`).

```sh
BOOKNOOK_ALLOW_REMOTE_TESTS=1 npm run verify:data
```
