# Интерфейс B.Nook / W.Nook

- Предпочтение владельца: минимум надписей. Не добавляйте слоганы, описания очевидных функций, учебные карточки и повторяющиеся заголовки.
- У действия должно быть одно короткое название. Не дублируйте его поясняющим абзацем и подписью к иконке.
- Для понятных иконок используйте `aria-label` и подсказку при наведении вместо постоянной подписи. Поля должны сохранять доступное имя.
- Показывайте пояснение, когда оно помогает принять решение или исправить ошибку: доступность текста книги, ограничения формата, последствия удаления.
- Сохраняйте текущие цвета и типографику. Меняйте визуальное направление только по просьбе владельца.
